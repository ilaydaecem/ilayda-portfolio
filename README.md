## `$ whoami`

A **single-page responsive portfolio** built with a dark **terminal / IDE aesthetic** — inspired by the tools I use every day. No frameworks, no build step: pure HTML5, Tailwind CSS (CDN), and vanilla JavaScript, deployed live on GitHub Pages.


## ✦ Features

| Feature | Description |
|---|---|
| **Terminal UI** | IDE-inspired dark theme with scan-line overlay, dot-grid hero, typed-text animation, and JetBrains Mono font |
| **Lightbox** | Click any project screenshot to open a full-screen, blur-backdrop modal with smooth spring animation. Close via ✕ button, overlay click, or `Escape` |
| **Responsive Design** | Mobile-first layout — collapses to a hamburger nav and single-column sections on small screens |
| **Scroll Reveal** | Intersection Observer–powered fade-in for every section heading, skill card, experience card, and education card |
| **Contact Form** | Terminal-windowed form (Name · Email · Message) with cyan focus rings, animated send button, and a simulated success state |
| **Live Clock** | Footer displays the current local time, updated every second |
| **Active Nav Highlight** | Nav links highlight automatically as you scroll through sections |

## 🚀 Local Development

No build step required — just serve the files:

```bash
# Clone
git clone https://github.com/ilaydaecem/ilayda-portfolio.git
cd ilayda-portfolio

# Serve (Python)
python3 -m http.server 8080
# → http://localhost:8080

# Or with Node
npx serve .
```
